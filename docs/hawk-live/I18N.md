# Bahasa ID / EN (standar terkunci, Aji 2026-11-14)

Setiap aplikasi HAWK punya tombol **ID / EN** di pojok kanan atas topbar. Bahasa Indonesia = default.
Pilihan disimpan di `localStorage['hawk.lang']` dan berlaku bersama untuk 5 portal hawk-live, app Finance 60 NV (`/`), dan iframe Demo Experience Center.

## Cara kerja
- `hawk-live/i18n.js` — mesin + kamus shell + pola (`PATTERNS`) + fallback per segmen `A · B`.
- `hawk-live/i18n-en.js` — kamus isi layar (frasa Indonesia persis → English).
- Layar tetap dirender dalam Bahasa Indonesia. Saat EN aktif, teks dan atribut `aria-label`/`title`/`placeholder` yang ada di kamus diganti; saat kembali ke ID teks asli dipulihkan persis. Teks yang belum ada di kamus tetap Indonesia.
- `data-noi18n` pada elemen = jangan diterjemahkan (mis. nama, kode).
- Dimuat paling akhir di setiap `hawk-live/*.html` dan setelah `HAWK.boot()` di `index.html`. CSS tombol disuntik oleh i18n.js (hawk.css tetap terkunci).
- Ponsel/tablet (≤1024px) di app 60 NV: satu tombol (bahasa aktif, ketuk untuk ganti); ≤480px tombol panduan walkthrough disembunyikan agar topbar muat.

## Menambah terjemahan
Tambahkan baris `'Teks Indonesia persis': 'English text'` di `i18n-en.js`. Untuk teks berpola (angka, nama), tambahkan regex di `PATTERNS` (i18n.js).

## Uji
`node tests/hawk-live/i18n.e2e.js` (termasuk di `tests/hawk-live/run-all.sh`).
